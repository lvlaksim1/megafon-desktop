# Manager mandate

The Project Manager may autonomously research public implementations, design architecture, write and refactor product code, add tests/CI/docs, create development branches/PRs, and merge ordinary reversible development changes that implement the owner's accepted product direction.

Owner approval is required before:

- changing product scope to B2B or away from a standalone Windows desktop application;
- issuing real-account requests that connect/disconnect paid services, change tariff/forwarding, accept/reject offers, or otherwise create external/bill-affecting effects;
- publishing a production release or changing authority/governance rules.

Never commit secrets or private account/browser data. Treat undocumented MegaFon contracts as volatile evidence and re-verify high-impact mutations from current browser logs before enabling them.
